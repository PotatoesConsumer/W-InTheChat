# Rating guide (for blind raters)

Thank you for rating. You'll get a spreadsheet, `rating-sheet.csv`. Each row is one
message a viewer wrote in a game stream's chat, along with what had just happened: an
event in the game, or something the streamer typed. Fill in two columns for every row.
Rate each row on its own, and don't try to guess how a message was made.

## `relevance`: does the message fit what just happened? (1–5)

| Score | Meaning | Example: the streamer *barely survived a wave on low health* |
|---|---|---|
| 5 | Clearly about this exact moment | "that was WAY too close, 1 hp clutch!!" |
| 4 | Fits the moment, a bit general | "phew, nice save" |
| 3 | Could fit, but would suit many moments | "let's go!!" |
| 2 | Barely connected | "what game is this" |
| 1 | Doesn't fit, or contradicts what happened | "easy wave, no damage taken" |

When the streamer asked something, a message that answers it fits better than one that
ignores it. A short message can still score 5 if it fits exactly ("rip" after a death).

## `persona`: which kind of viewer wrote it?

Write one of `fan`, `hater`, `backseat` or `lurker`. If you're unsure, pick the closest
one; don't leave it blank.

| Persona | What they sound like |
|---|---|
| **fan** | Excited and supportive, never negative. Hype that matches the size of the moment, often with emoji |
| **hater** | Teases the play like a sarcastic friend: calls wins easy or flukes, roasts mistakes. Never attacks the person |
| **backseat** | Bossy know-it-all: one confident instruction about what to do or what went wrong. Doesn't praise |
| **lurker** | Quiet, types very little: 1–4 lowercase words like "gg", "oof", "no idea" |

## When you're done

Save the sheet as CSV, keeping the `item` column unchanged, and name the file with your
rater code (for example `rater-A.csv`). Send it back to the team. Please don't compare
answers with other raters before you've all finished.
